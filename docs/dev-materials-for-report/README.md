# dev-materials-for-report/

本目录保存最终报告与阶段汇报所需的开发过程：决策依据、实际进展、测试发现和会议结论。每条记录注明日期、修改内容与验证结果，便于报告引用和复现。

开发记录写明涉及的前后端文件和依赖关系，例如 API 字段调整同时影响后端响应、浏览器类型和适配测试。测试记录注明执行目录、命令、环境、结果和待验证范围；模拟 HTTP 响应与真实数据库联调分别记录。

## 与外层 docs/ 的分工

- **`docs/` 根目录**：面向"项目本身"的稳定文档（需求、架构设计、课程资料）
- **本子目录**：面向"开发过程 / 报告素材"的文档（迭代记录、决策推演、bug 排查、会议纪要）

## 写作建议

- **及时记录**：在开发过程中把决策、问题和处理结果写进对应文档
- **统一格式**：每条记录建议带日期 `[YYYY-MM-DD]`，便于追溯
- **直接面向报告**：写文档时就当作是在写报告，最终可以直接复用内容
- **会议记录**：记录导师建议、讨论结论和后续任务，作为沟通与改进的依据
