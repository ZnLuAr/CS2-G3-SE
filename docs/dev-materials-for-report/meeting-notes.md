# 会议记录

> 记录组会、与学术导师（supervisor）的 meeting。
> Project update 与答辩需要展示团队协作与利益相关者沟通，会议记录是最直接的证据。
> 与导师的 meeting 尤其重要：导师的每条建议都应记录"我们怎么回应的"——采纳、调整还是论证后坚持。

---

## 模板（复制以下结构添加新条目）

### [YYYY-MM-DD] 会议主题（组会 / 导师 meeting）

- **参与人**：谁在场（缺勤的注明）
- **议题**：讨论了什么
- **结论**：决定了什么（没结论的写"待定 + 下次讨论时间"）
- **行动项**：谁、做什么、什么时候之前
- **导师反馈**：（仅导师 meeting）导师的意见与建议
