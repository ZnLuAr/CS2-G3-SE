# Skills 库

本目录包含项目的协作技能库，供各 agents 使用。

## 可用 Skills

### code-review
**代码审计** — 在 PR/合并前对代码改动进行全方位检查

- 业务逻辑审计（返回类型、异常使用、事务管理、业务规则）
- 安全性审计（输入验证、SQL 注入、密码处理、权限检查）
- 代码质量审计（命名、职责、复杂度、错误处理）
- 设计优雅度审计（抽象、继承、复杂度、职责划分）
- 性能审计（N+1 查询、索引、分页、缓存）
- 文档同步审计（architecture.md、README.md）

**注意**：本项目测试在后续统一编写，代码审计不包含测试维度。

**使用场景**：新增功能、修复 bug、重构代码、数据库改动

**快速开始**：
```bash
# 查看改动范围
git status --short
git diff --stat

# 根据改动类型选择对应的审计维度
# 详见 code-review/SKILL.md
```

### doc-audit
**文档审计** — 全面审计架构文档与代码的一致性

- 文档 → 代码：检查文档中描述的接口是否在代码中存在且匹配
- 代码 → 文档：检查代码中的公共接口是否在文档中说明
- 类型定义、函数签名、参数顺序、返回值类型的一致性
- 业务规则描述与代码注释的一致性
- 使用 sub-agent 并行审计各模块，生成详细报告

**注意**：不追求速度，追求全面和准确。逐节比对，不跳过任何章节。

**使用场景**：Phase 验收、大规模重构后、架构文档更新后的验证

**快速开始**：
```bash
/doc-audit
```

## 如何使用

1. 根据你的任务类型选择合适的 skill
2. 按照 skill 文档中的执行指引进行操作
3. 遵循审计清单逐项检查
4. 汇总审计结果并修正问题

## 如何添加新 Skill

1. 在 `.agents/skills/` 下创建新目录（如 `.agents/skills/new-skill/`）
2. 创建 `SKILL.md` 文档，包含：
   - 前置元数据（name、description）
   - 执行指引（按场景分类）
   - 检查清单（具体可执行的步骤）
   - 快速参考（常用命令、优先级）
   - 使用建议
3. 在本文件中添加说明
4. 在 `AGENTS.md` 中添加指向新 skill 的文档链接

---

## 与主项目 AGENTS.md 的关系

项目根目录的 `AGENTS.md` 包含指向本 skills 库的文档链接，确保各 agents 都能看到协作规范。

Skills 库放在 `.agents/skills/` 中，因为：
- 各 agents 都需要访问
- 属于项目协作资产，不是个人配置
- 便于版本控制和团队共享
