# 前端测试

在 `frontend/` 安装 npm 依赖后，执行 `npm test` 运行 `unit/` 下的 Vitest 测试；执行 `npm run build` 完成类型检查与生产构建。Playwright 通过 `npm run test:e2e` 运行 `e2e/` 下的浏览器测试，需要可用的 Edge 或 Chromium。已验证的两终端启动步骤和浏览器安装命令见[前端参与说明](../README.md#浏览器测试)。

单元测试覆盖认证输入合同、身份持久化、刷新复核、并发恢复、迟到响应与退出隔离、退出失败清理、HTTP 错误与请求中止、字符串 ID 边界、私有查询缓存、角色路由和公共状态组件。会员 `/profile`、`/orders`、`/orders/:orderId` 入口均检查角色范围。测试中的身份与 HTTP 响应由测试明确提供。

浏览器测试覆盖登录页和 404 的实际渲染，名称带 `mock` 的用例覆盖模拟认证下的导航、刷新、大整数账号显示、资料和订单入口、401 与退出服务不可用反馈。Windows 上运行浏览器测试时，使用两个终端分别管理 Vite 和 Playwright 服务。

带请求编号的命令存储、刷新恢复与核实、自然幂等操作、通知轮询，以及真实后端的认证、数据库权限、预约、销售和到课流程，随领域页面增加对应测试并独立记录联调结果。
