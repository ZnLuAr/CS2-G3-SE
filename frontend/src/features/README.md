# 功能域

每个功能域以 `routes.ts` 声明页面路径、显示名称、说明和角色范围；公共装配将声明注册到 Vue Router。认证域调用后端认证路径，提供登录表单和身份状态，后端认证 Logic 仍为占位。业务路由连接共享准备中页。实现业务页面时，在所属域内加入 API 类型、请求函数、查询与组件，并更新路由组件。

| 目录 | 负责内容 |
|---|---|
| `auth/` | 登录、退出、身份恢复和账号管理入口 |
| `members/` | 会员 `/profile` 本人资料及员工建档、查询与管理 |
| `products/` | 卡、课包、权益与赠卡规则 |
| `sales/` | 会员 `/orders`、`/orders/:orderId` 与员工销售、订单、收款、入场 |
| `courses/` | 教练、课程、场地、课次、学员名单与结束课次 |
| `reservations/` | 本人或代办预约、候补与候补人数 |
| `attendance/` | 会员本人签到、前台代签到、教练或管理员到课结算与更正 |
| `reviews/` | 会员评价、教练课次评价与管理员查询 |
| `measurements/` | 本人体测与教练授权录入、查询 |
| `equipment/` | 器械查询、报修与维护 |
| `reports/` | 经营统计、导出与日志快照 |
| `notifications/` | 本人通知与已读状态 |
| `recommendations/` | 本人及选定会员的课程推荐 |

领域 API 使用 HTTP 的 `camelCase` 字段。业务 ID 保持 `EntityId` 十进制字符串，可空字段使用 `null`，列表统一 `Page<T>`。查询键包含当前账号、目标和规范化筛选条件，查询取消信号交给公共客户端；写入成功后刷新相关功能域的查询。

带 `requestId` 的业务表单按架构合同保存当前标签页内的冻结输入和原请求编号，退出或切换账号时清理当前页面和缓存，待核实记录按操作者隔离保存。该命令状态与各领域表单一同实现。会员签到入口由 `/bookings` 承接，前台代签到由 `/front/bookings` 承接，结束课次由教练和管理员的课次页承接，复用到课和课次 API。

功能范围、负责人和交付状态见[功能清单](../../../docs/feature-list.csv)，输入输出与权限遵循[前端架构](../../../docs/architecture/frontend.md)和[后端 API 合同](../../../docs/architecture/backend.md#17-web-api)。
